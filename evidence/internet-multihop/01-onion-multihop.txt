=== PROCEDURE FOR THE FULL TEST ===
On each of 3 independent hosts:
  1. install Tor; add to torrc:
       HiddenServiceDir /var/lib/tor/airbot
       HiddenServicePort 9401 127.0.0.1:9401
  2. generate a relay identity, record its BLAKE3 fingerprint
  3. run: airbot relay --port 9401 --next <next>.onion:9402
On the client:
  4. pin all three fingerprints out-of-band (NOT over the same channel)
  5. AIRBOT_PRIVACY=1 airbot privacy-preflight
  6. run the chain and capture at each hop
Note: relays are addressed by .onion, so NO public IP is required on any host;
free-tier or self-hosted machines on separate networks are sufficient.
